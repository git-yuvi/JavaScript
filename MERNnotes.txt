-----------

METHOD
something.doSomething()

Example:
app.get()
arr.map()
res.json()

-----------

PROPERTY
something.value

Example:
req.body
req.params
process.env


----------

FUNCTION
doSomething()

Example:
require()
setTimeout()


----------

HOOK
Special React function

Example:
useState()
useEffect()
useContext()

----------

API
A collection/interface of functionality provided by
JavaScript, Node.js, Express, or another library.

Examples:
JavaScript Array API
Node.js File System API
Express API
Web API

-----------

One important distinction: an API isn't another type of method. An API is the broader interface/collection of functionality; that API can contain methods, functions, properties, classes, etc.
